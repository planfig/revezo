# Contributing

1. Node.js 24 or newer. `npm install` also enables the pre-commit secret check.
2. `npm test` and `npm run typecheck` must pass.
3. Use only fictional data in code, tests and docs (`example.com`, "Jane Doe").
4. New provider? See [docs/writing-a-plugin.md](docs/writing-a-plugin.md).

Commit with your GitHub "noreply" e-mail if you do not want your address in the public history.
